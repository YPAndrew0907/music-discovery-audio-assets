# Music Discovery Atlas audio assets

This release contains 5,018 attributed music excerpts for Music Discovery Atlas.

Download [human-readable credits](https://github.com/YPAndrew0907/music-discovery-audio-assets/releases/download/audio-5018-c9a8dbad3167-72d346776783/credits-5018.html) or [complete machine-readable credits](https://github.com/YPAndrew0907/music-discovery-audio-assets/releases/download/audio-5018-c9a8dbad3167-72d346776783/credits-5018.json) together with the audio. The archives contain the exact files named by those credits.
